# Interface language and RTL

botLANd ships an English interface with the localization machinery in place. No
machine translation is included: a language appears in the picker only after a
real translation file is added.

## Catalog

- `src/i18n/en.json` maps a **source string** (the English text) to its display
  value. English values equal their keys; the catalog exists so translators and
  tests have one complete list.
- `t(key, vars)` is typed against `keyof typeof en.json`, so a typo fails the
  build. `translate(value, vars)` is the runtime form for strings that come from
  outside the renderer (main-process status messages, known key-service errors).
- `tp(one, other, count, vars)` chooses a plural form with `Intl.PluralRules`.
  Both English forms are catalog entries.
- Placeholders use `{name}`. `tests/i18n.test.cjs` checks that every catalog value
  keeps the same placeholder set as its source key.

Run `npm run i18n:extract` after adding or changing UI text. It:
1. collects every `t('...')` / `tp('...', '...')` literal in `src` (dynamic keys
   are reported as errors), and
2. writes `src/i18n/en.json`, preserving values and any extra keys that are used
   through a dynamic lookup.

Main-process error text, console output and the schema fallbacks remain English
technical detail. They are displayed as sent; the renderer never translates
arbitrary IPC text with `t()`.

## Adding a language

1. Copy `src/i18n/en.json` to `<locale>.json` and translate the values.
2. Import it in `src/i18n/index.ts` and add it to the `messages` map.
3. Add `{ "id": "<locale>", "label": "...", "dir": "ltr" | "rtl", "userFacing": true }`
   to `src/i18n/locales.json`.
4. Add the language to the font subset if it needs glyphs outside
   `scripts/subset-fonts.cjs`'s range (`npm run fonts:subset`).
5. Run `npm test`, `npm run build` and the accessibility smoke.

Schema labels are data from the main process. A translation file may override
them without changing `electron/schema.cjs`:

- `schema.field.<sourceKey>` — field label (for example `schema.field.sv_hostname`)
- `schema.hint.<sourceKey>` — field hint
- `schema.choice.<sourceKey>.<value>` — select option label
- `schema.section.<English section name>` — configuration group heading

Missing entries fall back to the English label sent by the main process.

## RTL

`applyDocumentLocale` sets `<html lang>` and `<html dir>` from
`src/i18n/locales.json`. Layout uses logical CSS properties
(`inset-inline-*`, `margin-inline-*`, `border-inline-*`, `text-align: start/end`),
so the sidebar and panels mirror automatically. Directional icons and the
decorative hero art are mirrored by the `[dir=rtl]` rules at the end of
`src/styles.css`.

The accessibility smoke runs two hidden locales supplied by `src/i18n/index.ts`:

- `pseudo` — accented, ~20% wider strings for expansion/truncation checks.
- `pseudo-rtl` — the same strings with `dir="rtl"`.

The harness asserts no horizontal overflow and that the sidebar is on the right.
To preview them, pass a locale to the browser fixture:
`createDemoManager({ locale: 'pseudo-rtl' })` or set `locale` in `settings.json`;
they never appear in the language picker.
